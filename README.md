# The Ultimate Matching Theorem

This repository accompanies [*The Ultimate Matching Theorem*, Hexagon submission 2611.00294v1](https://hexagonmath.org/2611.00294v1), by **Michael Goldman, Francesco Grotto, and Dario Trevisan**, on Talagrand’s Ultimate Matching Conjecture.

## Documents

| Document | Description | Files |
|---|---|---|
| **umt** | The manuscript submitted to Hexagon, presenting the finite-exponent theorem and the failure of the conjecture at the endpoints. | [PDF](https://github.com/grottofrancesco/UltimateMatchingTheorem/blob/main/umt.pdf) · [LaTeX](https://github.com/grottofrancesco/UltimateMatchingTheorem/blob/main/umt.tex) |
| **finite-exponents** | The first version of the AI-generated solution of the ultimate matching problem for finite exponents. | [PDF](https://github.com/grottofrancesco/UltimateMatchingTheorem/blob/main/finite-exponents.pdf) · [LaTeX](https://github.com/grottofrancesco/UltimateMatchingTheorem/blob/main/finite-exponents.tex) |
| **endpoints** | The first version of the AI-generated derivation of the exact asymptotic matching cost at the endpoint exponent pairs $(2,\infty)$ and $(\infty,2)$, disproving the conjecture in those cases. | [PDF](https://github.com/grottofrancesco/UltimateMatchingTheorem/blob/main/endpoints.pdf) · [LaTeX](https://github.com/grottofrancesco/UltimateMatchingTheorem/blob/main/endpoints.tex) |
| **problem17.2.2** | An AI-generated solution of a Research Problem posed by M. Talagrand, concerning a technical fact related to the Ultimate Matching Conjecture. | [PDF](https://github.com/grottofrancesco/UltimateMatchingTheorem/blob/main/problem17.2.2.pdf) · [LaTeX](https://github.com/grottofrancesco/UltimateMatchingTheorem/blob/main/problem17.2.2.tex) |

Start with **umt** for the overall presentation. These manuscripts were developed through interactions with large language models, the first versions of the AI-generated solutions are "monolithic" and hard to read. We plan to give a fully digested, readable version of all arguments in these files in the near future.
